# 🎓 快乐学习乐园

一套面向 **6 岁儿童**的三科游戏化学习系统，通过游戏和测验的方式，科学、高效地学习：

- 🐞 **语文 · 拼音** — 声母/韵母/整体认读识别、看字选拼音、声调判断、拼音拼读、认字（人教版）
- 🔢 **数学 · 计算** — 20/100 以内加减、乘除、**连加减（如 13+6-7）、乘加/乘减**（动态出题，无限题量，苏教版进度）
- 🔤 **英语 · 拼读** — 字母音、首音字母、CVC 词族、**长元音、字母组合（ch/sh/th/wh）**、日常词汇（人教版）
- 📜 **语文 · 古诗** — 合肥市小学各年级必背古诗词，读、背、理解、猜作者，**🎙️ 跟读打分**（语音识别）
- ✏️ **语文 · 汉字** — **笔顺动画跟写**、笔顺 quiz、**组词练习**（人教版）

> 教材版本对齐：**语文人教版 · 数学苏教版 · 英语人教版**。

支持 **多孩子独立账号**（孩子由后台新建）、**家长管理后台**、**自定义学习/休息时长**（到点自动停学，休息后继续）、**分年级学习曲线**（依据合肥/安徽教学大纲）。


## ☁️ 部署到 Cloudflare Workers（D1 + 静态资源）

同一套前端，后端跑在 Cloudflare Workers 上，数据存 D1（SQLite）。无需本地 Node 常驻。

### 1. 安装依赖

```bash
pnpm install
```

### 2. 创建 D1 数据库

```bash
pnpm exec wrangler d1 create kid-learn-db
```

把输出的 `database_id` 填进 `wrangler.jsonc` 的 `d1_databases[0].database_id`。

### 3. 初始化表结构 + 播种题库

```bash
# 生成 migrations/seed.sql（管理员 PBKDF2 哈希 + 全部题库/古诗/汉字）
pnpm run seed:sql

# 建表
pnpm run d1:init

# 灌数据
pnpm run d1:seed
```

### 4. 设置会话密钥（生产必做）

```bash
pnpm exec wrangler secret put SESSION_SECRET
```

`wrangler.jsonc` 里的 `vars.SESSION_SECRET` 仅用于本地 dev，生产以 secret 为准。

### 5. 部署

```bash
pnpm run deploy
```

部署后访问 Workers 域名即可，管理员账号 `admin` / `19910109`（**请立即在后台修改密码**）。

### 本地开发 Workers 版

```bash
pnpm run dev:worker   # wrangler dev，本地 D1 模拟，http://127.0.0.1:8787
```

首次本地跑需要先对本地 D1 执行 `d1:init` / `d1:seed`（加 `--local`）。

### 两版差异

| | Node 版 (`npm start`) | Workers 版 (`pnpm run deploy`) |
|---|---|---|
| 数据库 | better-sqlite3 本地文件 | Cloudflare D1 |
| 会话 | express-session | HMAC 签名 cookie |
| 密码 | bcrypt | PBKDF2（Web Crypto） |
| 时区 | 服务器本地 | 固定 Asia/Shanghai |
| 题库播种 | 启动时自动 | `d1:seed` 一次性 |

> Workers 版代码在 `worker/`，题库生成脚本在 `scripts/generate-seed-sql.js`。前端 `public/` 两版共用，未改动。

## 🎯 分年级学习曲线（合肥/安徽教学大纲）

首页可选「我上几年级」，系统据此自动匹配难度与内容：

| 年级 | 数学 | 拼音/语文 | 英语 |
|------|------|-----------|------|
| 一 | 10以内加减 | 拼音声母韵母、认字 | 字母音、首音 |
| 二 | 100以内加减、乘法口诀 | 拼音拼读、看字读音 | CVC词族、日常词汇 |
| 三 | 乘除、万以内 | 古诗、理解 | 长元音、字母组合 |
| 四 | 乘除混合、运算律 | 古诗鉴赏 | 综合拼读 |
| 五 | 小数分数 | 古诗词积累 | 长单词 |
| 六 | 分数百分数 | 古诗词综合 | 综合阅读 |

出题时按年级过滤题库（`grade` 标签），数学按年级映射难度。

## 🔐 登录与多孩子

- 每个孩子**独立账号**，数据（进度/错题/统计）完全隔离。
- 家长用 `admin` 登录进入 **管理后台**，孩子用自己的账号登录进入学习页。
- 未登录访问任何页面会自动跳转到 **登录页**。

## 🛠️ 家长管理后台 `/admin.html`

- **👦 孩子管理**：添加 / 编辑 / 删除孩子；为每个孩子单独设置
  - 每日学习总时长（分钟）
  - 单次连续学习时长（分钟）
  - 休息（冷却）时长（分钟）
  - **自定义停学提示语**（到点显示给孩子的话）
  - 头像、年级、重置密码
- **📊 学习概览**：查看每个孩子的各科正确率、薄弱知识点、近 7 天学习时长、未攻克错题。
- **⚙️ 设置**：全局公告等。

## ⏱️ 计时停学机制

进入学习时开始计时，家长设置的时长达阈值后：

1. **到点自动停学**，全屏显示**自定义提示语** + 休息倒计时；
2. 休息（冷却）结束后出现「▶️ 继续学习」按钮，点击开启新的学习时段；
3. 当日总时长达标后显示「今天的学习任务完成啦」，需等次日。

> 计时在**服务端**累积（每 10 秒心跳上报，防作弊），锁定期间服务端拒绝出题/作答。

## 🧠 科学学习机制

| 机制 | 说明 |
|------|------|
| **间隔复习（SM-2 简化）** | 每题维护掌握度 0~5，答对按 `[0,1,2,4,7,15,30]` 天递增复习间隔；答错归零。到期题优先出现，对抗遗忘曲线。 |
| **错题本** | 答错自动进入错题本；重练需**连续答对 3 次**才标记"攻克"，攻克后从错题本移出。 |
| **动态难度** | 数学按难度 1/2/3 出题（简单=10以内，普通=20以内，挑战=100以内+乘除）。 |
| **即时反馈** | 每题立即判对错、显示正确答案与讲解，配音效/彩带动画，强化记忆。 |
| **每日目标 & 打卡** | 记录每日 XP、答题数、连续打卡天数。 |
| **成就系统** | 首次尝试、答对 10/50/100 题、三科小达人、攻克错题等成就徽章。 |

## 🔌 主要 API

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/profile` | 孩子档案 + 各科进度 |
| GET | `/api/next?subject=&difficulty=` | 取下一题（不泄露答案） |
| POST | `/api/answer` | 提交答案，返回对错/正确答案/XP |
| GET | `/api/review-next` | 取到期复习题 |
| GET | `/api/mistakes` | 错题本列表 |
| GET | `/api/mistake-next` | 错题重练一题 |
| GET | `/api/report` | 学习报告（学科正确率、薄弱点、打卡、成就） |

## 💡 给家长的建议

- 每天固定 15~20 分钟，**三科轮换**，保持新鲜感。
- 优先让孩子玩「快乐学习」，系统会自动安排复习。
- 用「学习报告」查看**薄弱知识点**，针对性鼓励。
- 多用具体的表扬（"你连对 5 题啦！"），比分数更能激发兴趣。
